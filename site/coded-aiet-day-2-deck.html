🖥️

What Claude Design is

You describe the deck you want. It builds the slides, the layout and the structure, inside the same conversation that already has your document in it.
📎It already has your context because you attached the report earlier in the chat
✏️You can change one slide by asking, rather than rebuilding the whole thing
📊It can carry the analysis through from the same data you gave it
It is not a design tool. It is a writing tool that outputs slides.
Section 1 1.2

A deck is a document
with a shape.

The shape is the prompt. Six things, and it is the same six as yesterday.
Audience
Who is in the room, and how long they have
Slide count
Say a number. Otherwise you get twelve.
The spine
Name every slide. This is the part people skip.
The numbers rule
Where figures may come from, and what to do when one is missing
Tone
Direct, or diplomatic. They produce very different decks.
The ask
What you want the room to do when it ends
Name the six slides yourself. If you cannot, the deck is not ready to build.
Before you build anything

A deck that looks right
and misquotes one number
is worse than no deck.

A rough draft gets questioned. A polished slide gets believed. The better it looks, the less anyone checks it.

Section 2 2.1

Gamma, in one line.

A presentation tool that generates the whole deck from a prompt, then lets you edit it like a web page. Design first, where Claude is writing first.
Gamma is stronger at

  • Themes, images and layout variety
  • Sharing as a link people can scroll
  • Speed from nothing to something
Claude Design is stronger at
  • Keeping your document in context
  • Getting the words right
  • Carrying analysis through from data
  • Changing one slide without a rebuild

Section 2 2.2

The export test.

Somebody will ask you for the PowerPoint. They always do. So the real question is not how it looks in the tool.
What usually survives
The words, the order, the basic layout
What usually shifts
Spacing, font substitution, anything overlapping
What usually breaks
Charts, custom graphics, and anything clever
What to do
Export once, early, before you have built twelve slides on a broken pattern
Run the export test in task 2, not the night before the meeting.

Section 3 3.1

Sometimes it calculates.
Sometimes it predicts.

When it writes and runs code on your file, it calculates. When it answers from the shape of the numbers, it predicts. You cannot tell which from looking at the answer.
This is yesterday's prediction slide, arriving with a budget attached. Ask it to show its working, every time.
Section 3 3.2

Ask what is wrong
before what it says.

Every real export is dirty. Nobody tells you which parts.
Duplicates
The same response counted twice
Blanks
Which some tools drop and some read as zero
Impossible values
A 7 on a scale that stops at 5
Spelling variants
One department, four names, four fake departments
The re-identifier
A comment that names the person who wrote it
The profiling prompt takes twenty seconds. Skipping it costs you the whole analysis.

Section 4 4.1

Four checks,
in this order.

Recount
Does the detail add up to the total? Do it yourself once.
Recompute
Is the percentage on the right base? Budget, not actual.
Re-source
Where did this figure come from? Name the cell.
Re-read
Does the sentence claim more than the number supports?
Four checks, about six minutes. Cheaper than one correction email to a board.

Section 5 5.1

Three places
a prompt can live.

Home 1
A document
Simple, portable, works anywhere. You paste it in every time.
Home 2
A Project
Instructions and files that apply to every chat inside it. Good for one ongoing job.
Home 3
A Skill
Claude loads it on its own when the task matches. You stop pasting entirely.
Start with the document. Promote the ones you actually reuse.A library of forty prompts you never open is not a library.
🧩

What a Skill is

A saved set of instructions with a name and a trigger. When your request matches the trigger, Claude loads it without being asked.
🏷️A name and a one line trigger that says when it should fire
📜The full instructions which are just your best prompt, written to work on any input of that type
🔁Consistent output because the same instructions run every time, not the ones you remembered
Worth making when you have done the same task three times. Not before.
